# Python ChatBot

PyBot is a simple chatbot built in Python. It can answer basic programming questions, perform mathematical calculations, remember the user's name, save chat history, and also provides a graphical user interface (GUI) using Tkinter.

## Features

-  Greets the user
-  Remembers the user's name
-  Saves chat history
-  Performs mathematical calculations
-  Shows current date and time
-  Shares random facts
-  Answers basic Python questions
-  Answers basic Java questions
-  Answers simple AI-related questions
-  Tkinter GUI version
-  Uses separate calculator module
